# Features

## ESP

- Player boxes with team filter
- Health bars (0–100 mapped to box height)
- Optional skeleton (WIP, needs bone matrix offsets)
- Bomb / defuse kit indicators

## Aimbot

- External cursor movement (no injection)
- FOV gate + smoothing factor
- Bone selection: `head`, `neck`, `chest`
- Activation key: `mouse5` by default

## Overlay

- Click-through layered window (`WS_EX_LAYERED | WS_EX_TRANSPARENT`)
- 7ms target frame, 12ms budget
- Runs at native resolution, DPI-aware
